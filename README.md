# taiko_no_tatsujin

Este é um projeto diy inspirado em: https://chauquest.com/index.php/engineering/diy-taiko-no-tatsujin-arcade-controller-complete-tutorial/

O objetivo é tornar o jogo Taiko no Tatsujin acessível e divertido para ser jogado em casa.

# Materias
Este código foi aplicado pensado na utilização de um arduino micro, é perfeitamente compatível com qualquer arduino desde que possua ao menos 4 pinos analogicos e suporte a HID

# Observações
Foi aplicado no código variáveis de acordo com a calibração dos meus materiais, para uma melhor experiência faça testes e altere as variáveis: *limiarMinimo* e *tempoBloqueio* pois elas irão variar de acordo com cada construção
